# Agent guidance

This repository contains the source for the personal website, including static page assets and resume documents.

## Development

- `index.html` is the site entry point; keep changes focused on the source content and assets.
- There is no build manifest in the repository. Review HTML changes locally without publishing them.
- Do not edit or regenerate resume PDFs unless the task specifically requests it.

## CI

- Before changing CI, inspect the current guidance in `pschmitt/ci-workflows`. Pin shared reusable workflow and action references to `@main`.
